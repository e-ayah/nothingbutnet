# Goals

Figma: https://www.figma.com/design/IQVHZ6RXr0zA6EzIyTMcix/Untitled?node-id=1-2

This is in my personal file for now and can be copied into the team file.

- Mobile: 393 × 852. Desktop: 1440 × 900.
- Active goals show the current angle, target, and a progress bar. A completed knee goal is shown too.
- The goal form includes a checkpoint selector, target angle, range hint, and Save goal button.
- Loading, error, empty, and saved examples are below the main screens.
- Both main screen frames use Auto Layout. The mobile elbow and shoulder cards are reusable components; desktop cards and remaining repeated controls still need component reuse.
- Font: Inter.
- Colors: cream #FFF8F0, burnt orange #B93815, brown #2D201B, secondary text #6F5D55, green #1F7A4D, pale green #E8F3EC, white #FFFFFF, track #F0E6DB.

I kept the cream background and burnt-orange buttons to match the other screens. Progress bars and clear angle labels make it easy to see how close each goal is, while green highlights progress and completed goals. The form stays short so setting a new goal feels straightforward.

Sample values and optimal ranges are illustrative. Progress is the portion of the starting-to-target distance covered: elbow (86.2−68)/(95−68) ≈ 68%; shoulder (49−40)/(60−40) = 45%.

These are editable design mockups, not working forms. Figma sync verified: the latest designs were checked in the browser and match the desktop file.
